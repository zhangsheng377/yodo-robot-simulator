# 训练模拟器 - 设计文档

> 配套文件：
> - `yodo_training.html` — 模拟器单文件实现
> - `训练场地观察记录.md` — 场地观察 + 推理记录
> - `比赛规则.md` (上级目录) — 比赛规则原始定义
>
> 目标用户：腾予（金钥匙南京市选拔赛参赛选手）+ 家长
> 用途：在家用电脑/平板/手机 + 游戏手柄**模拟比赛训练**（不替代比赛用车）

---

## 1. 目标与定位

### 1.1 训练目的

- 在没有真车的情况下，**练习瞄准、力度档位、转向、收球发射节奏**
- 熟悉场地布局、6 个圈的对称分布
- **反复试错** 1-2-3 圈 / 1-2-5 圈的不同路线
- 跑战术：**4 分钟限时** + **6 球消耗** + **过河** 三重压力下的决策

### 1.2 非目标（明确不做）

- ❌ **不用来替代真车训练** — 真车的反馈（电机延迟、球反弹、力度手感）模拟不出来
- ❌ **不接 BLE** — 这是网页，不是 App，不能连真实积木
- ❌ **不是游戏** — 没有关卡、没有故事、没有装饰炫技
- ❌ **不联网** — 纯前端单文件，浏览器双击就开

### 1.3 使用场景

- 家长带腾予**晚上在家练 30 分钟**
- 教练演示战术（投屏到电视）
- 比赛前**最后一次**走流程（4 分钟模拟赛）

## 2. 技术架构

### 2.1 单文件设计

```
yodo_training.html  (32 KB)
├── HTML body
│   ├── <canvas> 主画布 (900×600)
│   └── 右侧 <div id="panel"> 控制面板
├── CSS（暗色主题，内联）
└── JS（所有逻辑内联）
    ├── 输入层（键盘 + 手柄）
    ├── 状态对象 state
    ├── 物理层（车 + 球 + 碰撞）
    ├── 渲染层（场地/圈/车/球/HUD）
    └── 主循环（RAF）
```

**为什么单文件**：
- 用户可能用 U 盘拷贝到学校电脑、邮件发给教练、用浏览器历史记录打开
- 不需要服务器（NAS 已能直接打开 `file://` URL）
- 不用打包工具

### 2.2 渲染方案：Canvas 2D

- 不用 WebGL（2D 场景够用，调试简单）
- 不用 DOM 元素堆砌（性能差 + 不好对齐）
- 不用 SVG（重画 / 动画麻烦）
- 不用框架（React/Vue 都不必要）

### 2.3 渲染层职责

| 函数 | 职责 |
|---|---|
| `drawArena()` | 草地 + 河 + 桥 + 桥挡板 + 外边框 |
| `drawCircles()` | 6 个圈（带数字/角色标签/击中变色） |
| `drawBalls()` | 自由球（红/橙） |
| `drawCar()` | 小车（方块+4 角圆轮+黑色车头+装球小红点） |
| `drawAim()` | 瞄准线（虚线，按下发射时变黄） |
| `drawSpread()` | 落点散点圈（30 秒淡出） |
| `drawHUD()` | 顶部状态条（时间/分/球/撞挡数） |
| `updatePanel()` | 右侧控制面板数据更新 |

### 2.4 主循环

```javascript
let lastT = performance.now();
function loop(t) {
  const dt = Math.min(0.05, (t - lastT) / 1000);  // 限 dt 上限
  lastT = t;
  // 1. 计时
  // 2. 处理输入
  // 3. 更新物理（车、球）
  // 4. 渲染
  // 5. 更新面板
  requestAnimationFrame(loop);
}
```

**关键点**：
- `dt` 上限 0.05s = 防止切窗口回来时物理"跳一大步"
- 固定 60 FPS（浏览器 RAF 节奏）
- 渲染和物理不分离 tick（简单够用）

## 3. 场地模型

### 3.1 坐标系

- 原点在左上角
- 单位：像素
- 场地尺寸：900 × 600
- 长宽比 3:2 — 与训练照片观察一致

### 3.2 6 个圈（中心对称布局，编号 1-6）

| 编号 | 坐标 (x, y) | 角色 | 半径 | 颜色 |
|---|---|---|---|---|
| 1 | (85, 85) | **己方指挥部** | 45 | 黄色 |
| 2 | (130, 510) | 目标 | 45 | 白色 |
| 3 | (770, 90) | 目标 | 45 | 白色 |
| 4 | (815, 515) | **对方指挥部** | 45 | 蓝色 |
| 5 | (300, 200) | 目标（北岸） | 45 | 白色 |
| 6 | (600, 400) | 目标（南岸） | 45 | 白色 |

**对称逻辑**（180° 旋转对称）：
- 1 ↔ 4（对角）
- 2 ↔ 3（对角）
- 5 ↔ 6（垂直，被河隔开）

**为什么这么摆**：
- 1/2/3/4 实测自照片 132822（4 角分布）
- 5/6 推理：补足 6 个 + 对称原则 + 与河的关系（5 北 6 南）
- 用户 10/17 确认圈号 1-6

### 3.3 河（S 形蜿蜒）

```javascript
top:    [{0,240}, {180,220}, {340,240}, {520,260}, {720,250}, {900,280}]
bottom: [{0,380}, {180,360}, {340,380}, {520,400}, {720,390}, {900,420}]
```

- 用 6 个折点定义河的上下岸
- 河宽 ≈ 30 px
- **球进入河 = 掉河丢球**
- **车可以过桥**（不能直接穿河）

### 3.4 桥 + 桥挡板

```javascript
bridge:  x: 380, y: 260, w: 140, h: 130
railL:   x: 380, y: 240, w: 8,   h: 60
railR:   x: 512, y: 240, w: 8,   h: 60
```

- 桥面覆盖河的中段
- 桥两侧各 1 个竖直挡板（**家长 10/17 确认：挡板不许撞倒**）
- 挡板带"禁撞"字样提示
- 车撞挡板：**减速 70% + 报警 + 计数**（但允许通过，不阻挡推进）

### 3.5 外边框（带高度）

- 4 道棕色厚边（12 px）
- 模拟立体边框 + 高光（顶部 + 左侧亮色阴影）
- 球可反弹（保留 70% 速度）

### 3.6 6 个球初始位置

```javascript
[
  {x:200, y:380},  // 桥南
  {x:380, y:120},  // 河北
  {x:550, y:480},  // 下方
  {x:700, y:180},  // 河东北
  {x:480, y:300},  // 河上
  {x:250, y:450},  // 左下
]
```

**重要**：训练时用户可能重摆这些球，**模拟器提供"摆球模式"**（点击场地手动放球 = 手放 = 10 分）

### 3.7 指挥部标注

- 左上角**黄色**标注"己方指挥部"
- 右下角**蓝色**标注"对方指挥部"
- 车从己方指挥部 (60, 30) 出发

## 4. 物理模型

### 4.1 小车（双轮差速）

**状态**：
```javascript
car: { x, y, theta, vl, vr }
```

- `(x, y)` = 位置（车体中心）
- `theta` = 车头朝向（弧度）
- `vl, vr` = 左右轮速度（px/s）

**驱动模型**：
```javascript
if (up)    { vl += a*dt; vr += a*dt; }    // 前进：双轮同向
if (down)  { vl -= a*dt; vr -= a*dt; }    // 后退：双轮反向
if (left)  { vl -= a*0.8*dt; vr += a*0.8*dt; }  // 左转：差速（原地转）
if (right) { vl += a*0.8*dt; vr -= a*0.8*dt; }  // 右转：差速
```

**运动学**：
```javascript
v = (vl + vr) / 2          // 线速度
w = (vr - vl) / wheelbase  // 角速度（轮距 20 px）
x += v * cos(theta) * dt
y += v * sin(theta) * dt
theta += w * dt
```

**参数**：
- `accel = 80` px/s²
- `fric = 12` px/s²（每帧减摩擦）
- `maxV = 70` px/s
- `wheelbase = 20` px

**为什么用差速而不是 Ackerman**：
- 规则说"转弯是两轮方向不同"= 差速
- 原地转最灵活（坦克模式）

### 4.2 球（弹道 + 摩擦 + 重力）

**状态**：
```javascript
ball: { x, y, vx, vy, alive, flying, handPlaced }
```

**物理**（当 `physics` 开关打开）：
```javascript
vy += 80 * dt              // 重力（轻）
vx *= (1 - 0.3*dt)         // 摩擦（横向）
vy *= (1 - 0.3*dt)         // 摩擦（纵向）
```

**边框反弹**（保留 70% 速度）：
```javascript
if (x < 8)  { x = 8;  vx = +|vx| * 0.7; }
// 4 道边框同理
```

**掉河判定**：
```javascript
if (inRiver(x, y) && !onBridge(x, y)) {
  alive = false;  // 球没了
}
```

**击中目标圈**：
```javascript
const c = inCircle(x, y);  // 找最近的圈
if (c) {
  score += handPlaced ? 10 : 20;
}
```

**落地判定**（速度太小，停在地面）：
```javascript
if (hypot(vx, vy) < 8) {
  spreadDots.push({ x, y, hit: false });  // 记录落点
  alive = false;
}
```

### 4.3 碰撞检测

| 碰撞 | 检测方法 |
|---|---|
| 车 vs 外边框 | AABB（车半径 12 + 边框） |
| 车 vs 桥挡板 | AABB（车 + 8×60 挡板矩形） |
| 车 vs 圈 | 圆-圆距离（车中心 vs 圈中心） |
| 球 vs 外边框 | AABB（球半径 7 + 边框） |
| 球 vs 河 | 折线距离（点 vs 6 段折线） |
| 球 vs 桥 | 矩形（球 vs 140×130 桥面） |
| 球 vs 圈 | 圆-圆距离 |

### 4.4 几何辅助函数

```javascript
inCircle(x, y)        // 返回第一个包含 (x,y) 的圈，或 null
carInAnyCircle()      // 车体 5 点采样，至少一点在圈内
inRiver(x, y)         // 点 vs 河中心线折线距离
onBridge(x, y)        // 点在桥面矩形内
onRail(rail, x, y, r) // 点+半径 vs 挡板矩形
```

## 5. 输入系统

### 5.1 双源输入

- **键盘**（fallback，调试用）
- **游戏手柄**（primary，训练用）

### 5.2 键盘映射

| 键 | 动作 |
|---|---|
| `↑/W` | 前进 |
| `↓/S` | 后退 |
| `←/A` | 左转 |
| `→/D` | 右转 |
| `Z` | 收球 |
| `X` | 发射 |
| `C` | 切换瞄准线 |

**`X` 发射的特殊处理**：
- 按下时记录时间 `firePressStart`
- **按住时长决定力度档位**：
  - < 0.3s → 轻
  - 0.3-1.0s → 中
  - > 1.0s → 重
- 松开时根据时长调用 `tryFire(dt)`

### 5.3 手柄映射

| 控件 | 动作 |
|---|---|
| 左摇杆 X (axes[0]) | 左右 |
| 左摇杆 Y (axes[1]) | 前后（注意 Y 反向） |
| 方向键 (12/13/14/15) | 同上（fallback） |
| A 键 (button 0) | 收球（按下触发） |
| B 键 (button 1) | 发射（按下记录时间，松开发射） |
| X 键 (button 2) | 发射（备用） |
| RB (button 5) | 切换瞄准线 |

**手柄 API 关键坑**：
- `gamepadconnected` 事件**只给 ID**，不给轴/按键状态
- 轴数据**必须每帧 poll** `navigator.getGamepads()` 获取
- 死区 0.15（避免摇杆漂移）
- 按键要做边沿检测（用 `gpPrevX` 记录上次状态）

### 5.4 输入优先级

手柄按下时**覆盖**键盘状态（不冲突）— 因为手柄是 primary

## 6. 游戏规则实现

### 6.1 得分规则

| 行为 | 分数 |
|---|---|
| 收球 + 发射 击中目标 | 20 分 |
| 手放球 + 发射 击中目标 | 10 分 |
| 球掉河 | 0 分 + 球消失 |
| 球落圈外 | 0 分（无得分，但车可以再装新球） |

### 6.2 收球规则

```javascript
function tryCollect() {
  if (state.loadedBall) return;  // 已装：第二次按无效
  for (const b of state.balls) {
    if (!b.alive) continue;
    const d = hypot(b.x - car.x, b.y - car.y);
    if (d < 22) {
      b.alive = false;
      state.loadedBall = b;
    }
  }
}
```

**简化**：训练模拟器里 1 次按键就装好，**不模拟"必须按 2 次"**（真车的卷球机构是机械的，模拟器复刻没意义）。**待家长说明后是否加多级装球进度**。

### 6.3 发射规则

```javascript
function tryFire(pressDuration) {
  if (!state.loadedBall) return flash('没装球');
  if (!carInAnyCircle()) return flash('车不在圈内');

  // 力度档位
  const speed = pressDuration < 0.3 ? 5.0 :
                pressDuration < 1.0 ? 8.0 : 12.0;
  // 转换为初速度
  vx = cos(theta) * speed * 30;  // px/s
  vy = sin(theta) * speed * 30;
}
```

**发射约束**：
1. **车必须至少一车轮在圈内**（按 5 点采样检测）
2. **只装 1 颗球**（模拟规则"不能装多个否则浪费"）
3. **方向 = 车头方向**（不是全局瞄准线方向）

### 6.4 过河规则

```javascript
// 自动检测
if (car.y > BRIDGE.y + BRIDGE.h / 2) {
  state.crossed = true;
}

// 到达对方指挥部 = 比赛完成
if (hypot(car.x - HQ_THEM.x, car.y - HQ_THEM.y) < 60) {
  state.hqIn = true;
  state.running = false;  // 停止计时
}
```

**过河约束**：
- 只能从桥上过（车不能直接穿河）
- 桥挡板撞了不阻挡推进（但报警 + 计数 + 减速）
- 模拟器**不模拟"碰到挡板被弹回"或"过河失败"** — 简化：挡板只阻挡竖直方向（挡板高度内），水平可以通过

### 6.5 计时与时间到

- 倒计时 240 秒（4 分钟）
- HUD 实时显示 `mm:ss`
- 时间到：自动停止计时，弹出"时间到！总分 XX"
- **6 球用完不强制结束**（让腾予继续练过河）

### 6.6 难度开关

| 开关 | 默认 | 用途 |
|---|---|---|
| 瞄准线 | 开 | 显示车头方向虚线 |
| 落点散点圈 | 开 | 显示每次球的落点（30 秒淡出） |
| 球的物理 | 开 | 重力 + 摩擦 + 边框反弹 |
| 辅助显示 | 开 | 圈号 / 河名 / 指挥部标签 |

### 7.2 暗色主题

- 背景 `#1a1d23`（深灰）
- 面板 `#232830`（稍深）
- 强调色 `#4fc3f7`（青蓝）
- 警告 `#ef5350`（红）
- 成功 `#66bb6a`（绿）
- 金黄 `#ffd54f`（分）

**为什么暗色**：
- 训练时间可能是晚上（光污染少）
- 颜色对比强（场地是绿色草地，更突出）
- 减少屏幕耗电（笔记本/平板）

画在 Canvas 顶部 30 px 高度，半透明黑底白字：


### 7.4 右侧面板

**状态区**：
- 得分（大字黄色）
- 剩余时间（颜色随时间变化：绿 → 橙 → 红）
- 球数（剩/总）
- 车内装球
- 车体位置
- 车头朝向
- 是否在圈内（绿=在，红=否）
- 过河状态
- 桥挡板撞击次数

**显示开关**（4 个 toggle）：
- 瞄准线 / 落点散点 / 球的物理 / 辅助显示

**力度档位**（3 个 badge）：
- 短按 / 中按 / 长按 — 按住时高亮

**目标圈列表**（6 行）：
- 圈号 + 角色（己方/对方/目标）
- 已击中显示分数和次数

**控制按钮**：
- 重置场地
- 加一颗球
- 清空落点
- 摆球模式（点击场地手动放球）

**场地布局图例**（颜色块）：
- 帮用户记住哪个颜色代表什么

**操作说明**：
- 键盘 / 手柄 键位

### 7.5 实时反馈

- **flash()** 弹出文字（半透明黑底黄字，1.5s 自动消失）
  - "🔴 收球" / "🎯 中发！" / "💥 重发！"
  - "⚠️ 撞桥挡板！" / "💧 球掉河里了！"
  - "🌉 已过河！" / "🎉 到达对方指挥部！"

### 7.6 落点散点圈

- 每次球**停下**（击中/落圈外/掉河）画 1 个半透明圆
- **3 种颜色区分**：
  - 🟢 绿 = 击中
  - 🟠 橙 = 落圈外（场地内）
  - 🔵 蓝 = 掉河
- 30 秒后淡出
- **训练价值**：直观看到每次发射的"散布范围"

## 8. 调试与校准

### 8.1 校准项（需要在真车上验证）

| 参数 | 当前值 | 校准方法 |
|---|---|---|
| 力度档位 轻 (light) | 5.0 | 短按 0.1s，对应球飞多少米？调到 30% 场地宽度 |
| 力度档位 中 (mid) | 8.0 | 中按 0.5s，对应球飞多少米？调到 50% |
| 力度档位 重 (heavy) | 12.0 | 长按 2s，对应球飞多少米？调到能反弹命中 |
| 重力 80 px/s² | 待定 | 真球几乎不弹，调到 30-50 |
| 摩擦 0.3/s | 待定 | 真球滚动慢，调到 0.5-0.8 |
| 边框反弹 0.7 | 待定 | 真球反弹保留 ~50-60% |
| 按键时长阈值 0.3s/1.0s | 待定 | 真手柄力度档位区分点 |

### 8.2 调试开关

- `F12` → Console 看 JS 错误

- 改 `RIVER` 数组：调整河形
- 改 `BRIDGE`：调整桥位置
