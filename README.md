# 有度积木机器人比赛训练模拟器

一个**单文件 HTML** 的机器人比赛训练模拟器：双击文件、用浏览器打开就能玩，不需要联网、不需要服务器。

- 在线版：http://192.168.10.5:8091/ （局域网，Ctrl+F5 刷新）
- 当前版本：`v2.8 · 20261018-31`
- 离线文件：`yodo_training_v2.8_20261018-31.html`（约 128 KB，零外部依赖，`file://` 可直接运行）

## 这是什么

按比赛场地照片 + 家长口述规则做的训练工具，用来练**瞄准、站位、收球发射节奏、过桥**。
不是真车替代品：电机延迟、真实摩擦、球的手感都模拟不出来，只练决策和站位。

## 场地与规则要点（v2.8 · build-31）

- 场地 **600×900 竖屏**：我方基地右上、对岸基地左下；6 个靶圈半径 58
- 圈号：**我方 4/5/6，对岸 1/2/3**（对位 4↔3、5↔1、6↔2），只有对岸 1/2/3 圈有目标物（每圈 4 个）
- **射程固定**：`R0 = 408.10`（由标定锚点反推，`computeBaseRange()` 单点来源）
- **发射条件**：车体（170×100）与任一靶圈有重叠即可发射；整车四角必须留在场地内
- **落点判定**：飞行按落点判，落地后连续衰减弹跳（40→18→8.1→3.65→1.64→0.74px，共 6 段约 72px），**每段落点都判定**；弹跳撞框按镜面反射
- **可达**：第一落点能压中圈心的有 28 个有向对；打不到的只有 2↔6（其中 6→2 可靠弹跳蹭近侧拿 20 分）
- **桥**：两侧挡板只覆盖水面段，净通行宽 134；真碰到只报警、计数，**不减速、不影响操作**
- **控制区**：左圆摇杆控方向（松手归零、轻扫不动车）、右侧 A=发射 / B=收球、底部中间速度条（20~70 px/s）
  - A/B 是模拟器自定义（官方 App 无“收球”键，官方两钮是喇叭/发射）；键盘操作同样可用
